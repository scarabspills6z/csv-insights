# csv-insights

A small command-line tool that reads a CSV file and prints a compact profile: number of rows, empty cells, and min/max/mean for every numeric column.

## Usage

```bash
python csv_insights.py data.csv
```

## Example

```text
column       count   min     max     mean
price         120   1.50   99.00   23.71
```
